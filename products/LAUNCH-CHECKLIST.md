# Launch Checklist — print this and tick the boxes

One page. Do it once for your first product, then repeat per product. Everything you need is
already in this repo — `listing-copy.md`, `mockups.md`, `STOREFRONT.md`, `QUICKSTART-EMAIL.md`.

---

## ONE-TIME SETUP (do this once, ~30 min)
- [ ] Pick a **store name** (ideas in `STOREFRONT.md`). Keep it consistent everywhere.
- [ ] Create a **Gumroad** (or Payhip) account — this is your owned store + buyer email list.
- [ ] Create an **Etsy** seller account — this is your search traffic. (Etsy charges $0.20/listing + fees.)
- [ ] Paste the **store bio + About** from `STOREFRONT.md` into both.
- [ ] Install the **free eRank or Everbee** browser extension for keyword checks.

## PER PRODUCT (~45–60 min each)
**1. Validate the keyword**
- [ ] Search the product's lead keyword (see table below) in eRank/Everbee.
- [ ] Confirm: searches are healthy and competition isn't a wall. If weak, try the title-#2 keyword instead.

**2. Prep the files**
- [ ] Open the `.xlsx` in **Google Sheets once** (Drive → upload → open → *Save as Google Sheets*).
      Click the Dashboard + Summary tabs; confirm the totals match the numbers in `README.md`. ← only check I couldn't run for you
- [ ] (Optional) Export Email 1 from `QUICKSTART-EMAIL.md` as a "Read Me First" PDF to include in the download.

**3. Make 5 product images**
- [ ] Open Canva (free), 2000×2000 px, use the palette in `mockups.md`.
- [ ] Build the 5 slides from the product's `mockups.md` (spend the most time on images 1 & 2).

**4. Create the listing(s)**
- [ ] Gumroad: new product → upload `.xlsx` + `Setup-Guide.pdf` → paste title/description/short blurb from `listing-copy.md` → set price → enable instant delivery.
- [ ] Etsy: new **digital** listing → same files → paste title + **all 13 tags** + description from `listing-copy.md`.
- [ ] **Keep the AI-disclosure sentence** in the description; set "Made by" → *A member of my shop* ("Designed by").
- [ ] Add the **cross-sell snippet** (from `STOREFRONT.md`) to the bottom of the description.

**5. Wire up the buyer email**
- [ ] Gumroad: paste **Email 1** into the product's receipt/content; schedule **Email 2** (~day 4–5).
- [ ] Etsy: you can't email buyers off-platform — rely on the in-download "Read Me First" PDF + a short Etsy Message thank-you. No incentivized review asks.

## AFTER ALL PRODUCTS ARE LIVE
- [ ] Create the **3 bundle listings** (reuse the same files): Rental Investor $39 · Self-Employed $39 · Everything $69. Copy in `STOREFRONT.md`.
- [ ] Pin your best product in the Gumroad store; set the Etsy shop announcement.

## ONGOING (low effort)
- [ ] When a buyer reviews, reply with a thank-you.
- [ ] After 5–10 reviews on a product, **raise its price** (e.g. $19 → $24–29; realtor → $34–39).
- [ ] Watch which keyword/listing sells; clone the winner into an adjacent niche (the engine makes a new variant in ~10 min).

## Reality check (so you aren't discouraged)
First sale often takes ~30–60 days; expect **$100s/month building over ~6 months**, compounding as
reviews and listings stack. This is a steady, low-maintenance stream — not an overnight salary.
